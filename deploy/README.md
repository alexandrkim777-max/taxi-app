# Test server

One Ubuntu 24.04 machine (4 vCPU, 8 GB RAM, 80 GB SSD) runs everything: Caddy (HTTPS), the API, the
staff panel, PostgreSQL/PostGIS, OSRM (routes) and Nominatim (address search), all from
OpenStreetMap data for Uzbekistan.

```bash
# as root on a fresh server
git clone https://github.com/alexandrkim777-max/taxi-app.git /opt/taxi
/opt/taxi/deploy/setup.sh            # 20–30 min; address search finishes importing about an hour later
```

- Address: `https://<server-ip>.sslip.io` until we have our own domain (`DOMAIN=taxi.example.uz ./setup.sh`).
- Staff panel: `/admin/`. Phone apps: `EXPO_PUBLIC_API_URL=https://<domain>` (the `preview` build profile).
- Updates: `/opt/taxi/deploy/update.sh`.
- Secrets live only in `deploy/.env` on the server (mode 600), generated by the setup script.
- Only ports 22, 80 and 443 are open; the database and map services are internal.
- Backups: daily `pg_dump` to `/var/backups/taxi`, kept 14 days.
- Map tiles still come from OpenFreeMap in test builds; our own tile server (docs/maps.md) comes next.

This is a test server: SMS codes are written to the API log (`docker compose logs api | grep sms`) and
payments are pretend. Real passengers only after the SMS and payment contracts, on hosting in Uzbekistan.
